# الجزيرة العائمة — نموذج WebGL تجريبي

واجهة ثلاثية الأبعاد مستقلة: جزيرة صخرية تطفو في السماء، يعلوها عشب وزهور
وتتدلّى من قاعدتها الممزّقة نباتات متسلّقة — بأسلوب الجزر المعلّقة.
رياح حيّة، إضاءة تتغيّر مع وقت اليوم، وسلسلة مؤثرات سينمائية.

## الواقعية — كيف تحقّقت
- **إضاءة بيئية (IBL):** سماء إجرائية (سُحُب عالية + بحر غيوم تحت الجزيرة)
  تُخبز إلى environment map عبر `PMREMGenerator`، فالسماء والإضاءة متطابقتان دائماً.
- **انسداد ضوئي مخبوز:** عمق الشقوق ومقدار رؤية السماء يُحسبان أثناء توليد
  الصخرة ويُخزنان في الألوان الرأسية.
- **ضوء مرتدّ من الغيوم:** بحر الغيوم تحت الجزيرة عاكس ضخم — بدونه تتحوّل
  القاعدة إلى كتلة سوداء.
- **العشب:** شفرات منحنية بمقطع عرضي مستدير، معتمة عند الجذر، وتنقل الضوء
  من خلفها (translucency) — وهي التفصيلة التي تُقنع العين.
- **ما بعد المعالجة:** عمق ميدان، Bloom، تدرّج لوني سينمائي، Vignette، حبيبات فيلم،
  وزيغ لوني خفيف — كلها مكتوبة يدوياً في `postfx.js` (لا EffectComposer، لا CDN).

## التشغيل
مجرد فتح الصفحة عبر خادم محلي (ليس `file://` بسبب تحميل الـ GLB):

```bash
python3 -m http.server 8899
# ثم: http://localhost:8899/3d/index.html
```

أو من خلال GitHub Pages مباشرة: `<live-url>/3d/`.

## البنية
| الملف | الدور |
|---|---|
| `index.html` | الصفحة + لوحة التحكم الزجاجية (عربي RTL) |
| `js/noise.js` | Simplex 3D + fbm + ridged — يولّد شكل الصخرة والتوزيع |
| `js/rock-garden.js` | المشهد كاملاً: الجزيرة، السماء، النثر، الرياح، الإضاءة، الكاميرا |
| `js/postfx.js` | سلسلة ما بعد المعالجة (DoF/Bloom/Grade/Vignette/Grain/CA) |
| `blender/rock_garden.py` | سكربت بليندر لتوليد صخرة أعلى جودة وتصديرها GLB |
| `assets/rock.glb` | (اختياري) ناتج بليندر — يُحمَّل تلقائياً إن وُجد |

Three.js يُحمَّل محلياً من `v2/lib/three.min.js` (r137). **لا يوجد أي CDN خارجي**
حتى تعمل الصفحة داخل شبكة الجزيرة.

## كيف يعمل النثر
1. تُبنى الصخرة كـ IcosahedronGeometry مُزاحة بـ fbm + ridged noise.
2. يُبنى Sampler يوزّع نقاطاً على المثلثات بوزن المساحة، ويرفض الوجوه شديدة
   الانحدار (`normal.y < 0.34`) — لا ينمو شيء على الجدران العمودية.
3. العشب والزهور `InstancedMesh` واحد لكل نوع (رسمة واحدة لعشرات الآلاف).
4. الرياح تتم في الـ vertex shader عبر `onBeforeCompile` — بدون أي تكلفة CPU.

## مسار بليندر
```bash
blender --background --python 3d/blender/rock_garden.py -- --out 3d/assets/rock.glb
```
عند وجود الملف يستبدل المشهد الصخرة الإجرائية به، ويعيد النثر على سطحه نفسه
دون أي تعديل في الكود. الشرط الوحيد: mesh واحد، Y للأعلى، القاعدة عند y=0،
وألوان رأسية باسم `Col` (السكربت يضبط ذلك كله).

العشب والزهور **لا** تُصدَّر من بليندر — نثرها في المتصفح أسرع بكثير من
تصدير مئات الآلاف من الشفرات في ملف GLB.
